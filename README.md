# Pizza Ordering System

A VB.NET Windows Forms app for taking pizza orders and summarising them.

## Features
- 4 pizza sizes (small, medium, large, party) and 4 extras (drink, salad, pasta, dessert)
- Any combination of the 8 items in a single order
- Subtotal, 5% VAT (calculated by a dedicated function) and order total
- Running totals for all orders, shown in a modal summary form

## Prices
| Item | Price |
|---|---|
| Small / Medium / Large / Party pizza | 30 / 35 / 40 / 50 |
| Drink / Salad / Pasta / Dessert | 5 / 10 / 10 / 15 |

## Run it
Download the latest build from the **Releases** page and run `PizzaOrderingSystem.exe`
(self-contained, no .NET install needed), or open the `.sln` in Visual Studio and press F5.

## Built with
VB.NET, Windows Forms, .NET
